# Conventions

- **Memory file:** `AGENTS.md` is canonical; `CLAUDE.md` and `GEMINI.md` are
  symlinks (or synced copies).
- **Tickets — claim first; open one only for work you are delivering now.**
  Linear context is injected at session start; read it before starting. Search
  the board for a ticket that already covers the work and claim it. Open a new
  one only when nothing covers **work you are actually delivering in this
  session** — never for a follow-up you thought of, an idea, or something you
  noticed in passing. Those go in your one owner update as a line
  (`feed-status-posts`); a ticket is what someone opens when they decide to do
  the work, not a place to park a suggestion. Skip trivial fixes and plain
  questions entirely. Close on delivery with proof (what changed, the PR link,
  a screenshot or recording). The `tickets` skill takes any explicit tracker
  action. Why the restraint: 100+ agents each closing a session by filing what
  they noticed pushed this board to 275 open tickets, 257 of them opened in a
  single month — and 220 sit in Todo, never started by anyone.
- **Parallel work:** multi-surface changes use `agents teams` — see
  `parallel-teams`.
