# Personal Stack

Default to Node 24, Next.js, Bun, React, Tailwind, zustand, and lucide-react on the frontend; Python 3.12, FastAPI, uv, pydantic, loguru, and Supabase/Postgres on the backend. Use TypeScript, Bun, built-in Python type hints, `.env.dev`/`.env.prod`, and permanent permissions in `~/.claude/settings.json` after asking once.
