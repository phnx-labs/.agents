# UI Work — See It Before "Done", Design It for the Eyes

A visual change is verified only after you inspect the rendered result on the machine doing the work. Use the configured browser automatically, and use `agents computer` element mode for native interaction; coordinate clicks and `--raise` must not take over the user’s active machine. Lead plans with visible behavior, build product-faithful mockups, and present two or three variations when a genuine design choice belongs to the user.
