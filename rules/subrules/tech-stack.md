# Tooling & Stack Conventions

Drive real interfaces with the task-native tools instead of guessing from prose or HTML: `agents browser` for the web and `agents computer` for native UI (each has a skill that teaches when and how to use it), `agents pty` for interactive terminals, `agents teams` for parallel coding, and `agents secrets` for credentials. Render charts as inline SVG or ASCII with the product's design tokens, never CDN chart libraries.
