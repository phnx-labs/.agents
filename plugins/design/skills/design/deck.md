# Presentation design

Read `design-core.md` beside this file. Create or refine the story and visual system of
slides using the existing deck, product guidelines, and supplied evidence.

1. Establish audience, purpose, required format, and the narrative. Inspect the existing
   slides visually when refining; retain useful templates, type, palette, and navigation.
2. Use the existing presentations capability for PowerPoint or another editable deck
   format it supports. Use `artifacts` for a standalone HTML presentation when that is
   the requested deliverable. Do not promise an export pipeline that has not been run.
3. Give each slide one main point, supported by legible evidence or a meaningful visual.
   Reuse the product's tokens and assets. Use `dataviz.md` for charts/data stories and
   `diagram.md` for relationships; read these references only when needed.
4. Inspect every slide at presentation size, including the densest ones. Check clipping,
   readable type, contrast, and consistency. Exercise navigation and any requested
   animation; review a bounded clip when timing matters. For revisions, compare the
   affected slides before and after.
5. Deliver and inspect the actual requested file or presentation. State anything missing
   or unverified, and use the shared presentation and artifact-location guidance.
